# ============================================================
# 部署后在面板上能改什么（不用回到这里）
# ============================================================
# 基础配置  : 协议（vmess / vless / trojan）、UUID、Trojan 密码、
#             WebSocket 路径、本地端口、自定义域名、Argo Token
# 落地与出站: 出站模式（直连 / 走代理链路）、一级代理、落地节点
#             链路顺序：容器 -> 一级代理 -> 落地节点 -> 目标
#             地址写法：socks5://user:pass@host:port 或 http://host:port
#             地址格式不对会在保存时被拦下（不会静默忽略）
# 出站测试  : 保存后可在「出站链路连通性测试」里验一遍 —— socks5 会做完整握手
#             （连账号密码一起验），http 只探端口可达性
# 出口检测  : 「出口 IP 检测」查的是流量最终从哪个 IP 出去。
#             ⚠️ 它和「地区优选源」里选的入口节点在哪个国家没有关系：
#             入口只决定客户端从哪个 CDN 边缘接入，出口由 sing-box 的出站决定。
#             本项目 sing-box 跑在容器里，所以直连模式下出口恒为容器所在地。
#             （CFNext 能「选哪个地区就出哪个地区」，是因为它的代理代码跑在
#              Cloudflare 边缘上 —— 那是另一套架构，别把两者混为一谈。）
#             要换出口国家：出站模式改成「走代理链路」，落地节点填目标国家的代理。
# 优选节点  : 优选 IP 列表（每行一条，支持 IP:端口#名称、IPv6 写 [::1]:443）
#             自定义优选域名
# 地区优选源: 勾选香港/台湾/日本/新加坡/美国/韩国，一键从社区维护的地区池拉节点。
#             这些源下发的每一行都自带地区标记，所以节点名会直接变成
#             「香港-01」「日本-02」这种 —— 地区名来自源里的标记，
#             不是拿 IP 去反查地理位置，因此不依赖任何地理库。
#             ⚠️ 节点名描述的是「入口在哪个地区」，不是出口。
#             同一个地区拉多次会自动接着编号（香港-11、香港-12…），不会撞名。
#             也可以填自定义源 URL：每行一条，支持 纯IP / IP:端口 / IP:端口#名称。
# 在线测速  : 粘贴一批地址 -> 并发 TCP 测延迟 -> 按延迟排序 -> 一键把前 N 个
#             回填进优选列表。回填后记得再点一次「保存并生效」才会下发。
# 配置备份  : 一键导出 / 导入 config.json
